# cass-community.github.io-v01

This was the original version of the website for the Consortium for the Advancement of Scientific Software (CASS): <https://cass.community/>.  It has been superceded by a new version, which lives at <https://github.com/cass-community>.  Consequently, this repo has been marked as `archived` in GitHub and should be of historical interest, at most.
